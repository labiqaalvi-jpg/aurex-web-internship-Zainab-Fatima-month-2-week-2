## Overview
This repository contains the Task 2 project for the AUREX Full-Stack Engineering Internship (Month 2). The goal is to integrate a REST API with React using `useState` and `useEffect` hooks, while handling loading, error, empty, and search/filter states.

## Features
- **API Integration:** Fetches user data dynamically from JSONPlaceholder REST API.
- **Async State Management:** Uses `useState` and `useEffect` hooks for asynchronous data processing.
- **UI States:** Supports Loading, Error, Empty, and Data display states.
- **Search & Filter:** Interactive search bar to filter records in real-time.

- JavaScript
- HTML5 / CSS3
- Git & GitHub
